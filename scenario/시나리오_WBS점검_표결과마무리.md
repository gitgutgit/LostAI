## 3. 화면 규칙 (이번에 바뀐 것)

- **표결은 질문 카드 종류에 따라 두 가지**다. 화면 안내 문구가 카드에 맞춰 바뀐다.
  - **찬반 카드**(선택지가 찬성/반대뿐이거나 주장 하나 + 반대): 손가락 **3 = 좋음, 2 = 보통, 1 = 싫음**. 말로 "3", "좋아요", "보통", "싫어요", "찬성", "반대"도 한 표.
  - **선택지 카드**(실제 선택지 2~4개, 예: "화요일이랑 목요일 중에"): 손가락이나 "2번", "option two"로 **번호 고르기**(주현 PR #38 방식).
  - 주먹(0)과 5, 카드 범위 밖의 번호는 표로 세지 않는다.
- **표결 여는 법**: "투표하죠"(열린 질문이 있을 때) 또는 2명 이상이 2초 안에 손가락을 보이기. 마지막 표 뒤 5초 조용하면 마감(말로 연 표결은 아무도 안 내면 20초).
- **SPLIT = 동점**: 1위가 둘 이상일 때만. 그 외에는 CONVERGED(결과 화면). 찬반 카드 결과는 좋음·보통·싫음 막대, 선택지 카드 결과는 선택지 막대와 바늘.
- **CLOSED**: "회의를 종료하죠", "오늘은 여기까지", "회의 마칠게요", "end the meeting" 같은 말이 나오면 끝 화면. 자동으로 닫히지 않는다. **✕ 회의 화면으로** 버튼이나 "회의 계속하죠"로 돌아간다.

## 5. 끝 화면에서 확인할 것 (L15)

| 자리 | 기대 내용 |
|---|---|
| 제목 | `1 decided, 1 open` |
| 카드 Q2 (노란 표지) | **Decision needed** — 출시일 01-14 vs 01-21, 선택지 1 민아 / 2 (지원 또는 하은) |
| 카드 Q1 | 성능 테스트는 통합 테스트 다음 (초록), `Vote: 3 good, 1 okay, 0 no` |
| 카드 Last edits | 최근 변경 3개와 줄 번호 (예: 액션 L14, 웹훅 행 L11, 3.3 일정 L10) |
| 숫자 | 문서 편집 수 · 되돌린 수 / 표결 2회 / **남은 결정 1** |
| 버튼 | 오른쪽 위 **✕ 회의 화면으로** (누르기 전까지 끝 화면 유지) |

## 7. 알려진 한계

- 화면 문구는 영상 시안(render v0.4)에 맞춰 영어다. 표결 안내에만 한국어(좋음 · 보통 · 싫음)를 같이 적었다.
- L4·L5처럼 두 사람이 다른 값을 말하면 질문 카드가 **선택지 카드(1 준호 병행 / 2 지원 순차)**가 될 수 있다. 그러면 L6 표결은 번호 고르기가 된다. 이 대본의 SPLIT → CONVERGED 흐름을 그대로 쓰려면 손가락을 1·2로 바꿔 보인다(첫 표결: 지원 2, 하은 2, 준호 1, 민아 1 → 동점 / 재표결: 지원·하은·민아 2, 준호 1 → 2번).
- 좋음·보통·싫음 흐름을 확실히 보이려면 L6을 "제 안에 찬반 투표하죠"처럼 한 안에 대한 표결로 부른다.
- L10에서 질문이 실제로 '해결됨'이 되는지, 3.3 일정이 함께 고쳐지는지는 LIVE 에디터의 판단에 달려 있다. 리허설에서 확인한다.
- 끝 화면 카드는 질문 3개 + Last edits 1개까지만 보인다. 질문이 더 많으면 제목 숫자에만 들어간다.
